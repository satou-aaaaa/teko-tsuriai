# てこのつりあい

棒の目盛り（フック）におもりをつるして、てこを水平につりあわせる。いちばん少ないおもりの数を目指す、だれでも同じ1日3問のパズル。小学6年の理科「てこのはたらき（てこの規則性）」が、遊ぶうちに身につきます。

- 遊ぶ: <https://satou-aaaaa.github.io/teko-tsuriai/>
- 下でおもり（10g・20g など）を選び、フックの番号を押すとつるせます。同じおもりのフックをもう一度押すとはずれ、別のおもりを選んで押すと取りかえます。
- てこをかたむけるはたらきは「おもりの重さ × 支点からのきょり（目盛りの数）」。左と右でこの数が同じになると、てこは水平につりあいます。いくつもつるしたときは、それぞれのかけ算をたします。棒の重さは考えません。
- はじめからつるしてあるおもり（点線）は動かせず、×のフックにはつるせません。手もちのおもりの数にも限りがあります。
- いちばん少ないおもりの数は、問題を作るときにつるし方を数えて出しています（問題の上に出ます）。その数でつりあわせ、ヒントも使わなければ★3つ。つりあうと、左右の「重さ×きょり」の式が出ます。
- 今日の3問（うで4目盛り・5目盛り・6目盛り）はだれでも同じで1日1回。上級（おもり4種類を2つ・メーターとヒントなし）、何度でも遊べる練習、種類ごとの記録が残るてこ帳、実績があります。時間制限はありません。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（てこの形や答えは入りません）。
